# WhatsApp tools

Run `uv run pytest` for fixture tests. They start no browser and send no messages.
Run `uv run ruff check src tests` and `uv run ruff format --check src tests` before opening a PR.

Client repositories own their group names and sending permissions. Pass the exact destination
from project or tenant configuration. Verify linked status or read a group with the commands
in README.md. A live send needs an approved destination and message.
